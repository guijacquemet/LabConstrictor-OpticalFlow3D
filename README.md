## How to Download and Install OpticalFlow3D Profiler?

The installer would only be available once OpticalFlow3D Profiler developer has created a release.
Please, go to [this page](.tools/docs/download_executable.md) and check if the installing instructions are there.
In case there is no documentation there, please [create an issue](https://github.com/guijacquemet/LabConstrictor-OpticalFlow3D/issues) asking the developer to create a release.
